人間の感情というのは非常に複雑で、愛する形も様々です。

愛する。という一言の周りにたくさんの想いがくっついてますね。

愛や喜び、憎しみ　悲しみなど色んな感情が渦巻く。

自分を愛せない日もあるし、自分を愛せる日もある。そんな日々を繰り返し人生を紡いでいきます。

何が正しいかどうかなんて正解はありません。

それぞれの手の中に　選択はゆだねられています。

波のように揺れたり変化する感情を表現シてみようと思いました。
